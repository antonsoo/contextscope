# Literal tokenizer text verification, 2026-10-12

Implementation: `08e77a3a7f2fd2611987d2c7a62e0a127bfeb935`.
Baseline: `71f3a1a02d6975f395b38a499b9a3881a6123a1b`.
This is source and local-artifact verification. No npm release, tag or hosted
site is updated; package version remains 0.3.3.

A valid prompt or tool result containing `<|endoftext|>` previously caused
`contextscope analyze` to exit 1 with `Disallowed special token found`.
The source fix counts those characters as ordinary text, without enabling
control tokens, deleting text or substituting an estimate. The shared counter
also stops rejecting otherwise valid Anthropic requests.

| Invalid browser imports rejected, prior report preserved | 8/8 | 8/8 |

The [study](../studies/token-literals/README.md) covers all three supported
request families, tool definitions and results, a batch envelope, gzip, a
repeated-prefix cache scenario and two pinned public tokenizer source files.
Bodies are constructed around synthetic strings or public code, not recorded
provider calls. Public-code licenses and original hashes are retained.

OpenAI's native tiktoken 0.12.0 `encode_ordinary` agrees with all 54 direct
probes and all 120 extracted text segments. Chat message framing is checked
separately: the existing five-token adjustment is preserved. The literal
`<|endoftext|>` has seven ordinary o200k_base tokens; 256 adjacent spellings
have 1,537. No claim is made about unmodeled provider framing or live billing.

## Compatibility and reproduction

Full JSON reports for all 11 bundled examples and all 240 reconstructed public
trajectories (10,555 requests) are byte-identical. Both old and new tokenizers
were actually run; this comparison includes token totals, findings and cache
simulations, with source and reconstructed-body hash checks. It does not measure
how often delimiter strings occur in other users' logs.

From a clean exported checkout, with Node 24:

```sh
npm ci
npm run lint
npm run typecheck
npm test
npm run build
npm run test:browser
npm pack
npm install --prefix /tmp/contextscope-installed ./antonsoloviev-contextscope-0.3.3.tgz
uv venv --python 3.12 /tmp/token-oracle
uv pip install --python /tmp/token-oracle/bin/python -r studies/token-literals/requirements.txt
node studies/token-literals/replay.mjs /tmp/contextscope-installed/node_modules/@antonsoloviev/contextscope /tmp/literal-installed.json verify /tmp/token-oracle/bin/python
node studies/token-literals/browser.mjs . /tmp/literal-browser.json verify
```

Repeat the installed replay with the Node 20 executable to check the runtime
floor. Detailed results are in the
[verification receipt](../studies/token-literals/evidence/verification.json).
Ordinary text counts remain specific to o200k_base, Claude counts remain
estimates, and cache behavior remains a simulation with its existing limits.
